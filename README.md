Project Description

This project uses Artificial Intelligence, Machine Learning, and Data Science to investigate water-related challenges in Africa, particularly in the Province of Gauteng. Using publicly available datasets, we perform data preprocessing, exploratory data analysis, feature engineering, machine learning modelling, and model evaluation to identify patterns and develop data-driven insights that can contribute to improved water security and resource management.

The repository contains the datasets, data-cleaning and analysis notebooks, machine learning models, visualizations, results, and supporting documentation for the project.
